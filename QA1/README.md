# Основы тестирования

## Цель проекта

Систематизировать базовые понятия тестирования и роль QA в жизненном цикле продукта.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- исследованы терминология и стандарты тестирования;
- сопоставлены виды и уровни тестирования;
- проанализированы модели разработки и принципы обеспечения качества.

## Использованные инструменты

Markdown, ISTQB Glossary, Agile Manifesto.

## Полученный результат

В каталоге `src` сохранено: 5 Markdown-документов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Открыть документы `src/task_1.md`–`src/task_5.md` в любом Markdown-просмотрщике.

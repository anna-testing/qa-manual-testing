# Мобильное тестирование

## Цель проекта

Изучить особенности тестирования мобильных приложений и инструменты диагностики Android.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- проанализированы мобильные платформы и типы приложений;
- подготовлены инструкции по работе с эмуляторами и Logcat;
- исследованы мобильные логи и возможности Charles Proxy.

## Использованные инструменты

Android Studio, Logcat, Charles Proxy, Markdown.

## Полученный результат

В каталоге `src` сохранено: 5 Markdown-документов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Открыть документы `src/task_1.md`–`src/task_5.md`; демонстрационная запись находится в каталоге `src`.

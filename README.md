# Manual QA Portfolio

## Цель направления

Продемонстрировать навыки ручного тестирования и подготовки тестовой документации.

## Что реализовано лично

- тест-кейсы, чек-листы, тест-планы и баг-репорты;
- материалы по тест-дизайну и анализу требований;
- проверки веб-приложений, REST API и мобильных приложений;
- анализ базовых рисков веб-безопасности.

## Использованные инструменты

Markdown, Postman, Swagger, Chrome DevTools, Android Studio, Logcat, Charles Proxy и табличные редакторы.

## Полученный результат

Подготовлен набор воспроизводимых QA-артефактов, размещённых в каталогах `src` соответствующих проектов.

## Запуск и просмотр

Открыть README выбранного проекта и перейти к перечисленным документам или импортируемым коллекциям в каталоге `src`.

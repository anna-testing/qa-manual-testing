# Анализ рынка вакансий

## Цель проекта

Оценить требования к QA-специалистам и определить направления дальнейшего развития.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- проанализирована выборка вакансий;
- составлена таблица требований и обязанностей;
- выполнен SWOT-анализ профессиональных компетенций.

## Использованные инструменты

Markdown, Microsoft Excel, SWOT-анализ.

## Полученный результат

В каталоге `src` сохранено: 2 Markdown-документов. Эти материалы подтверждают выполненную работу.

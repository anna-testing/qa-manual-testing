# Backend-тестирование

## Цель проекта

Проверить REST API и закрепить навыки работы с запросами, ответами и данными.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- проанализированы методы REST API и структура JSON;
- создана и экспортирована Postman-коллекция;
- сопоставлены реляционные и нереляционные базы данных.

## Использованные инструменты

Postman, Swagger, JSON, REST API, Markdown.

## Полученный результат

В каталоге `src` сохранено: 3 Markdown-документов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Импортировать файл `src/JSONPetstory Tests.postman_collection.json` в Postman; аналитические материалы находятся в `src/task_*.md`.

## Реляционные и нереляционные базы данных

### Отличия реляционных и нереляционных БД

| **Характеристика** | **Реляционные БД** | **Нереляционные БД** |
|--------------|----------|------------|
| **Структура данных** | Табличная | Коллекции, документы |
| **Язык управления** | SQL | Различные модели данных |
| **Целостность данных** | Поддерживается | Не поддерживается |
| **Транзакции** | Поддерживаются | Не поддерживаются |

### Плюсы и минусы реляционных и нереляционных БД

#### Реляционные БД

| **Плюсы** | **Минусы** |
|--------------|----------|
| Поддержка транзакций и целостности данных | Жесткая структура данных |
| Мощный язык SQL | Сложность масштабирования |
| Широкая поддержка и использование | Высокая нагрузка на диск и память |

#### Нереляционные БД

| **Плюсы** | **Минусы** |
|--------------|----------|
| Гибкая структура данных | Отсутствие поддержки транзакций и целостности данных |
| Легкость масштабирования | Ограниченная поддержка запросов |
| Высокая производительность | Новые технологии и модели данных |

## Отличия СУБД

### Сравнение MySQL и PostgreSQL

| **Характеристика** | **MySQL** | **PostgreSQL** |
|--------------|----------|------------|
| **Поддержка транзакций** | Поддерживается | Поддерживается |
| **Типы данных** | Ограниченный набор | Мощная поддержка типов данных |
| **Язык управления** | SQL | SQL |
| **Масштабирование** | Среднее | Высокое |

### Сравнение MongoDB и Cassandra

| **Характеристика** | **MongoDB** | **Cassandra** |
|--------------|----------|------------|
| **Модель данных** | Документная | Ключ-значение |
| **Гибкость структуры** | Высокая | Низкая |
| **Масштабирование** | Высокое | Очень высокое |
| **Язык запросов** | MongoDB | CQL |

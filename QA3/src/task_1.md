## Тестирование поля ввода логина

### Классы эквивалентности

1. Пустая строка: пустая строка или пробельные символы.
2. Короткая строка: строки минимальной длины (например, 1-5 символов).
3. Длинная строка: строки максимальной длины (например, 100-1000 символов).
4. Строка с пробельными символами: строки, содержащие только пробельные символы (пробел, табуляция, перевод строки и т.п.).
5. Строка с спецсимволами: строки, содержащие специальные символы (!, @, #, $, % и т.п.).
6. Строка с иероглифами: строки, содержащие китайские иероглифы или другие не латинские и не кириллические символы.
7. Строка с смешанными символами: строки, содержащие смесь различных типов символов (буквы, цифры, спецсимволы).
8. Выбор символов для тестирования

### Для тестирования каждого класса эквивалентности можно выбрать следующие символы:

1. Пустая строка: ""
2. Короткая строка: "zx", "12", "_-"
3. Длинная строка: строка из 1000 символов (например, "аbcd" * 250)
4. Строка с пробельными символами: " ", "\t\t", "\n\n"
5. Строка с спецсимволами: "~!@#$%^&*()_+-="
6. Строка с иероглифами: "", ""
7. Строка с смешанными символами: "qA4!@#α"

# Тестовые артефакты

## Цель проекта

Освоить подготовку основной тестовой документации для проверки веб-продукта.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- подготовлены тест-кейсы и чек-листы;
- оформлены баг-репорты и тест-план;
- собраны тестовые данные и пользовательские сценарии.

## Использованные инструменты

Markdown, техники документирования тестов.

## Полученный результат

В каталоге `src` сохранено: 7 Markdown-документов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Открыть документы `src/task_1.md`–`src/task_7.md` в любом Markdown-просмотрщике.

__Идентификатор тест-кейса:__ A001

__Название тест-кейса:__ Проверка успешной авторизации пользователя с логином standard_user

__Предусловия:__ Пользователь зарегистрирован в системе с логином standard_user и паролем secret_sauce.

__Шаги выполнения:__

* Ввести в поле «Username» значение standard_user.
* Ввести в поле «Password» значение secret_sauce.
* Нажать кнопку «Login».

__Идентификатор тест-кейса:__ AN002

__Название тест-кейса:__ Проверка наличия ограничения по количеству попыток ввода пароля

__Шаги выполнения:__
* Открыть страницу авторизации.
* Ввести в поле «Username» c клавиатуры один из известных логинов
* Ввести в поле «Password» произвольный пароль
* Нажать кнопку «Login»
* Повторить ввод пароля в поле «Password» и нажатие кнопки «Login» 16 раз

__Ожидаемый результат:__ нет ограничений по количеству попыток ввода пароля 

__Фактический результат:__ нет ограничений по количеству попыток ввода пароля

__Идентификатор тест-кейса:__ AN003

__Название тест-кейса:__ размер пароля

__Шаги выполнения:__

# Тестовый сценарий: Авторизация с использованием различных браузеров

1. Перейти на страницу [Авторизация в демонстрационном интернет-магазине](https://www.saucedemo.com/) в браузере Google Chrome версии 136.0.7103.119.
2. Ввести корректные логин и пароль.
3. Нажать кнопку "Войти".
4. Проверить, что пользователь авторизован и перенаправлен на главную страницу сайта.
5. Повторить шаги 1-4 в браузерах Mozilla Firefox, Microsoft Edge и Safari.

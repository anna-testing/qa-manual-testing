### **Инструменты DevTools: Польза для тестировщика**
| Вкладка / Инструмент      | Назначение                                                                 | Польза для тестировщика                                                                 |
|---------------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------------------------|
| **Elements**              | Инспектор HTML/CSS, изменение структуры DOM в реальном времени.           | Поиск багов вёрстки, проверка адаптивности, тестирование динамического контента.          |
| **Console**               | Просмотр ошибок JavaScript, выполнение команд.                            | Логирование ошибок, ручной вызов функций для проверки сценариев.                          |
| **Sources**               | Отладка кода, работа с исходниками и картами кода (source maps).          | Пошаговая отладка, проверка работы скриптов при ошибках.                                  |
| **Network**               | Мониторинг HTTP-запросов (статусы, заголовки, тело).                     | Анализ API-вызовов, проверка медленных запросов, тестирование нагрузки.                   |
| **Performance**           | Запись и анализ производительности (рендеринг, загрузка).                | Выявление "тормозов", оптимизация скорости отклика.                                       |
| **Memory**                | Диагностика утечек памяти.                                                | Тестирование стабильности приложения при долгой работе.                                   |
| **Application**           | Управление локальным хранилищем (LocalStorage, Cookies, IndexedDB).      | Проверка сохранения данных, очистка кеша, тестирование офлайн-режима.                     |
| **Security**              | Проверка сертификатов, CSP (Content Security Policy).                    | Поиск уязвимостей, валидация HTTPS.                                                       |
| **Lighthouse**            | Автоматический аудит (производительность, SEO, доступность).             | Генерация отчётов для улучшения качества продукта.                                        |
| **Recorder** 🆕           | Запись и воспроизведение пользовательских сценариев.                     | **Автоматизация ручных тестов:**<br>- Запись шагов для регрессионного тестирования.<br>- Генерация скриптов (Puppeteer).<br>- Документирование багов с воспроизводимыми сценариями. |

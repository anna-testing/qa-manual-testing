# Веб-тестирование

## Цель проекта

Проверить работу веб-приложения на уровне интерфейса, браузера и сетевого взаимодействия.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- проанализирована клиент-серверная архитектура;
- исследованы HTTP, HTTPS и cookies;
- подготовлены UI-проверки и результаты HTML-валидации.

## Использованные инструменты

Chrome DevTools, HTTP/HTTPS, HTML Validator, Markdown.

## Полученный результат

В каталоге `src` сохранено: 7 Markdown-документов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Открыть документы `src/task_1.md`–`src/task_7.md`; интерактивные проверки повторить в браузере через DevTools.

# Виды и уровни тестирования

## Цель проекта

Систематизировать классификацию тестирования и применить разные уровни доступа к системе.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- составлена классификация видов тестирования;
- проанализированы уровни тестирования;
- подготовлены проверки по подходам Black-box и Grey-box.

## Использованные инструменты

Markdown, Black-box testing, Grey-box testing.

## Полученный результат

В каталоге `src` сохранено: 5 Markdown-документов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Открыть документы `src/task_1.md`–`src/task_5.md` в любом Markdown-просмотрщике.

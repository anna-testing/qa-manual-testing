# Работа с дефектами

## Цель проекта

Освоить поиск, классификацию и документирование дефектов программного продукта.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- систематизированы виды и причины дефектов;
- подготовлены баг-репорты;
- описан жизненный цикл дефекта.

## Использованные инструменты

Markdown, техники локализации дефектов.

## Полученный результат

В каталоге `src` сохранено: 4 Markdown-документов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Открыть документы `src/task_1.md`–`src/task_4.md` в любом Markdown-просмотрщике.
